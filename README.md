# PubChem Bot

Telegram-бот-справочник по химическим веществам. Пользователь присылает название, бот находит вещество через публичный API [PubChem PUG REST](https://pubchem.ncbi.nlm.nih.gov/docs/pug-rest) и сохраняет его в базу SQLite без дублей. Раз в сутки бот сам перепроверяет базу и записывает, что изменилось в источнике.

## Возможности

- Поиск по названию: формула, молярная масса, XLogP, SMILES, InChIKey и ссылка на карточку PubChem.
- Кэш: повторный запрос того же названия, даже в другом регистре или с лишними пробелами, не идёт в API.
- Дедупликация по InChIKey: «aspirin» и «acetylsalicylic acid» хранятся как одно вещество с двумя синонимами.
- Регулярное обновление базы с журналом изменённых полей.
- Ограничение частоты запросов (4 в секунду при лимите PubChem 5) и повторы с растущей паузой при перегрузке API.
- Команды `/history` (последние запросы) и `/stats` (размер базы и доля ответов из кэша).

## Как устроено

```
bot.py      Telegram: команды, форматирование ответа, расписание обновлений
service.py  Логика: поиск (кэш → API → сохранение) и регулярное обновление
pubchem.py  Клиент API: лимит частоты, повторы, разбор и проверка ответа
db.py       SQLite: схема, нормализация названий, сохранение без дублей
tests/      19 тестов на подменённом API
```

Путь запроса:

1. Название нормализуется: нижний регистр, лишние пробелы, разные виды тире приводятся к одному.
2. Если такое название уже искали, ответ берётся из базы.
3. Иначе идёт запрос в PubChem, ответ проверяется на наличие обязательных полей.
4. Вещество сохраняется по InChIKey. Если оно уже есть под другим названием, добавляется только синоним.
5. Запрос пишется в журнал со статусом `api`, `cache`, `not_found` или `error`.

| Таблица | Что хранит | Ключ |
| --- | --- | --- |
| `compounds` | одно вещество — одна строка | InChIKey |
| `aliases` | все названия, под которыми его искали (это и кэш) | нормализованное название |
| `queries` | журнал запросов пользователей | id |
| `changes` | что поменялось при обновлениях | id |

## Решения

**Ключ — InChIKey, а не название.** У одного вещества десятки названий, а InChIKey вычисляется из структуры молекулы и один на вещество. Названия хранятся отдельно, в таблице синонимов.

**Громкая ошибка вместо тихих пустых данных.** В 2025 году PubChem переименовал свойства SMILES (`IsomericSMILES` → `SMILES`, `CanonicalSMILES` → `ConnectivitySMILES`). Со старыми именами API не падает, а молча возвращает ответ без этих полей. Поэтому отсутствие обязательного поля в ответе считается ошибкой.

**Противоречие не перезаписывается.** Если при обновлении CID вдруг указывает на другую молекулу (InChIKey не совпал), запись остаётся прежней и помечается как ошибка.

**Повторяются только временные сбои.** Ошибки 429 и 5xx повторяются с паузой 1 и 2 секунды, после трёх попыток бот сдаётся. Ошибки 400 и 404 означают, что вещества нет, и повтор не поможет.

**Логика отделена от Telegram.** `service.py` не знает про Telegram, поэтому тестируется без бота и подключается к другому интерфейсу.

## Запуск

Нужен Python 3.10 или новее и токен бота от [@BotFather](https://t.me/BotFather).

```bash
git clone https://github.com/<username>/pubchem-bot.git
cd pubchem-bot
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env               # Windows: copy .env.example .env
# впиши токен в .env
python bot.py
```

Тесты не требуют интернета:

```bash
python -m pytest -q
```
